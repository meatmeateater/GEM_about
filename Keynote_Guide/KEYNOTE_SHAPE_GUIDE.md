# Keynote 自訂裁切形狀｜製作與作業存證指引

## 幾何形狀定義與 SwiftUI 對應

在課堂作業要求中，需使用 Keynote 繪製自訂幾何圖形，並於 App 中作為遮罩（Mask / ClipShape）使用。
專案中的 [`SwiftUI/GEMStageCutShape.swift`](../SwiftUI/GEMStageCutShape.swift) 已使用 SwiftUI `Path` 重現本幾何形狀，用於主視覺（Hero）與舞台現場照片的非對稱現代舞台切角裁切：

```text
(0%, 0%) P1 --------------------------------------- P2 (100%, 0%)
|                                                   |
|                                                   |
|                                                   |
(0%, 90%) P5                                        |
 \                                                  P3 (100%, 83%)
  \                                                /
   \--------------------- P4 ---------------------/
                     (38%, 100%)
```

### 控制點座標百分比（依順時針方向）：
1. **P1**: `(0.00 * w, 0.00 * h)` —— 左上頂點
2. **P2**: `(1.00 * w, 0.00 * h)` —— 右上頂點
3. **P3**: `(1.00 * w, 0.83 * h)` —— 右側切角起點
4. **P4**: `(0.38 * w, 1.00 * h)` —— 底部最低尖角頂點
5. **P5**: `(0.00 * w, 0.90 * h)` —— 左側切角起點

## Mac Keynote 實作與存證步驟

> [!NOTE]
> 依課堂要求，實體 Keynote 原檔（`.key`）與繪製過程截圖需在 macOS Keynote 軟體中實際操作完成。

1. **開啟 Keynote**：建立一份空白簡報，插入一個自訂寬高比的矩形作為畫布參考。
2. **使用筆形工具繪圖**：
   - 點選上方工具列「形狀」→「以筆繪圖」（Draw with Pen）。
   - 依照上述 5 個控制點位置，順時針依次點擊以建立封閉五邊形。
3. **微調控制點座標**：
   - 選取頂點確認為折線點（Sharp Point），確保邊緣俐落。
   - 套用紫金色填色（例如 `#3E1F58`），移除外框線。
4. **截圖存證與存檔（待使用者執行）**：
   - 截取包含 Keynote 控制點的視窗畫面。
   - 將檔案儲存為 `GEM_Stage_Shape.key`，放置於本資料夾（`Keynote_Guide/`）。
